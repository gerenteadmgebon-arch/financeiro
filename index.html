Ativar o acesso por e-mail

Administrador definido: gerente.admgebon@gmail.com. O papel só é reconhecido após confirmar esse e-mail. A permissão é validada pelas regras no servidor.

Cole somente o firebaseConfig público. Não use JSON de conta de serviço, senha ou chave privada.

Passos para ativar
  1. No Firebase Console, crie ou escolha o projeto dedicado a esta central. Cadastre o aplicativo Web e copie o objeto firebaseConfig no campo acima.
  2. Em Authentication → Sign-in method, habilite E-mail/senha e, na mesma seção, Link por e-mail (login sem senha). A página não solicita senha.
  3. Em Authentication → Settings → Authorized domains, adicione o domínio publicado do GitHub Pages.
  4. Crie o Cloud Firestore Standard em modo de produção. Baixe as regras abaixo e publique-as na aba Rules. Elas já definem seu e-mail como administrador. Se o projeto tiver outros sistemas, integre as regras sem substituir as existentes; permissões amplas existentes também precisam ser revisadas.
  5. Publique o index.html configurado na pasta do GitHub Pages. A entrada por link exige a página publicada em HTTPS; abrir somente o arquivo local não ativa o login.
  6. Entre com gerente.admgebon@gmail.com, abra o link recebido e confirme o e-mail. Use E-mails permitidos → Cadastrar e liberar. Cadastre também os seis links em Configurar links.

Os e-mails permitidos e os links ficam no servidor. O HTML baixado não inclui a lista de usuários nem os links protegidos.

Limite publicado pelo Firebase para envio de links de entrada: 5 e-mails/dia no plano Spark e 25.000/dia no Blaze. Confira o plano e as cotas oficiais antes da ativação. Nenhuma mudança de plano é realizada por esta página.

Conferência na implantação: apenas seu e-mail verificado administra; autorizado acessa sem editar; bloqueado e não cadastrado não veem links; liberação e bloqueio são compartilhados entre dispositivos. A integração real ainda depende da ativação do projeto.
